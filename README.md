# Pipeline de Auditoria e Cálculo de Bônus (SQL)

Repositório contendo a resolução de um desafio prático de banco de dados aplicado ao setor de Recursos Humanos e Controladoria. O projeto foca na modularização de consultas analíticas utilizando múltiplas CTEs conectadas em formato de pipeline de dados.

# Descrição do Desafio

O objetivo do projeto é estruturar o cálculo automatizado da folha de bonificação anual para uma área específica da empresa. A regra de negócio exige isolar colaboradores elegíveis (departamento de TI com certificação ativa), consolidar o montante salarial desse grupo e aplicar uma taxa de bonificação de 12% sobre o total.

UTILIZEI: SQL, CTES, WITH.
